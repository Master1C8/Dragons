# macOS staged app publication

The macOS builder previously copied directly to the requested final `.app` path, so an error after the first file write could leave a partially modified app there. `build_game.py` now creates a private staging directory in the output parent, constructs the app there, validates the requested assets and ad-hoc signature, and publishes with macOS `renamex_np(RENAME_EXCL)`. The rename does not replace an existing path. The signature is verified again at the actual published path. On an ordinary pre-publication failure the task-owned staging directory is removed; a hard termination can leave it behind. If cleanup after rename or final-path verification fails, the published app may remain and is not reported as successful. This is a local app-copy build, not a player installer or production release.
