On 2026-11-07 the owner explicitly authorized beginning the full source inventory and Russian localization while the readability of Ъ/Ь in a small game window remains an open risk. This is permission to proceed with source work, not a visual acceptance or a release. The remaining feasibility and delivery limitations remain in HANDOFF.md.

The pinned original macOS build and UnityPy 1.25.4 were used. The existing source-bound extractors exported the English Yarn table and the TextMeshProUGUI objects in each of the nine pinned serialized assets to `localization/work/source-inventory-20261107/`. These are raw candidate fields, not classified visible strings, unique translations, or a coverage denominator.

Reproduction from a clean output directory: run `localization/dialogue_locale.py '<original app>/Contents/Resources/Data/sharedassets1.assets' --export <new output>/mac-yarn.json`, then run `localization/ui_locale.py '<original app>/Contents/Resources/Data' <asset> --export <new output>/mac-ui-<asset>.json` for each named asset. Use the project's pinned UnityPy environment. Both extractors reject unsupported source hashes and do not modify the installed game. The untracked working exports contain game source data and remain local; the recipes and object fingerprints are tracked.
