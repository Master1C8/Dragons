# Source inventory: initial extraction checkpoint

On 2026-11-07 the owner explicitly authorized beginning the full source inventory and Russian localization while the readability of Ъ/Ь in a small game window remains an open risk. This is permission to proceed with source work, not a visual acceptance or a release. The remaining feasibility and delivery limitations remain in HANDOFF.md.

The pinned original macOS build and UnityPy 1.25.4 were used. The existing source-bound extractors exported the English Yarn table and the TextMeshProUGUI objects in each of the nine pinned serialized assets to `localization/work/source-inventory-20261107/`. Yarn output `mac-yarn.json` contains 1,839 stable candidate line IDs and has SHA-256 `83ce70cbab11f1d75240548763cdc9ff9cb348db165beace51620f7c5890dd75`. The source object itself is pinned and its parser verifies an exact byte round trip. The nine UI exports contain 138 objects, 137 nonempty: 12, 14, 76, 6, 6, 6, 6, 11 and 1 in `level0` through `level6`, `sharedassets0.assets`, and `sharedassets1.assets`, respectively. These are raw candidate fields, not classified visible strings, unique translations, or a coverage denominator.

Reproduction from a clean output directory: run `localization/dialogue_locale.py '<original app>/Contents/Resources/Data/sharedassets1.assets' --export <new output>/mac-yarn.json`, then run `localization/ui_locale.py '<original app>/Contents/Resources/Data' <asset> --export <new output>/mac-ui-<asset>.json` for each named asset. Use the project's pinned UnityPy environment. Both extractors reject unsupported source hashes and do not modify the installed game. The untracked working exports contain game source data and remain local; the recipes and object fingerprints are tracked.

This checkpoint is not a complete source handoff. Pending: classify all values by actual runtime role and exact-preservation requirements; cover non-TMP UI, settings, generated/managed-code strings, bundles, media and every other in-scope resource family; bind Windows-version differences to stable source IDs; trace special scenes and semantic dependencies; build and verify a complete preserve-exactly manifest and validator. Exclude text baked into textures by the owner's decision and record that exclusion. Complete extraction and review precede the estimate, glossary-readiness checks and ordinary translation.
